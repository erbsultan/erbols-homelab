Garmoniya Center NGO Website

Многоязычный официальный сайт для ННО, собранный на Astro и TypeScript и размещённый на production-сервере Ubuntu в UZTELECOM Cloud.

официальный домен активен HTTPS с Let's Encrypt Google Workspace email активен

Обзор

Это практический production-деплой для Garmoniya Center. Сайт поддерживает русский, узбекский на латинице и английский и уже работает на garmoniya-center.uz.

Моя часть работы: сам сайт и понятный путь деплоя — Docker multi-stage build, Docker Compose на сервере, host Nginx reverse proxy и ручной deployment script.

Настройка сервера

  • Подготовил Ubuntu 24.04 VPS в UZTELECOM Cloud.
  • Настроил UFW, чтобы были открыты только нужные порты.
  • Включил Fail2Ban для защиты SSH.
  • Настроил вход по SSH-ключу и отключил password login.
  • Настроил host Nginx как reverse proxy перед сервисом в Docker Compose.
  • Включил HTTPS для официального домена через Let's Encrypt.

Деплой

Приложение собирается через Docker multi-stage build и запускается через Docker Compose. GitLab CI/CD сейчас проверяет проект, а production-деплой выполняется ручным скриптом, чтобы каждый релиз был явным и легко проверяемым.

Текущий статус

Официальный домен garmoniya-center.uz активен и работает через HTTPS. Официальная почта info@garmoniya-center.uz активна через Google Workspace.

Планируется

  • Admin panel для обновления контента.
  • Telegram/contact-form request system.
  • Mobile app на следующем этапе.

Что я прокачал

Проект дал больше практики с реальным Linux-сервером, Docker-деплоем, настройкой Nginx reverse proxy и базовым production hardening. Конфигурация специально оставлена простой и понятной, без лишних инструментов, которые проекту пока не нужны.
